Comienzo por verificar o instalar la versión de Python correcta. En este caso 3.11, ya que debe ser compatible con las librerías xgboost>=2.0 y shap>=0.45.

Creo la carpeta del proyecto en la siguiente ruta: D:\Juan\tfm-scoring y la abro con VSCode.

Creo el entorno virtual:

py -3.11 -m venv .venv

y lo activo:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass (necesario para la ejecución de scripts)

.venv\Scripts\Activate.ps1

Ahora selecciono el intérprete, usando el comando  "Python: Select Interpreter" y elijo .venv\Scripts\python.exe

Nota: Para usar los comandos debo escribir > primero en la barra superior


Instalo las extensiones necesarias: Python, Pylance y Jupyter
